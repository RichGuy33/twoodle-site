# Comment ajouter un widget couple sur l'écran d'accueil de l'iPhone (pas à pas)

[Par l'équipe Twoodle](https://twoodle.app/about/) · novembre 2026

> **Transparence:** nous faisons Twoodle, une app iPhone pour couples. Les étapes ci-dessous sont celles d'iOS, elles valent donc pour n'importe quelle app de widgets pour couples. Nous prenons Twoodle comme exemple.

La version courte : maintenez le doigt sur un emplacement vide de votre écran d'accueil, touchez **+**, cherchez votre app, choisissez une taille, touchez **Ajouter un widget**. Ensuite, faites-en autant à votre partenaire sur son téléphone. Deux minutes, grand maximum.

C'est cette dernière partie qui coince chez la plupart des couples. L'un installe l'app, envoie un joli petit dessin, et l'autre répond : « Je ne vois rien. » Forcément : il n'a jamais mis le widget sur son écran. L'app, c'est l'expéditeur. Le widget, c'est la boîte aux lettres.

Voici le tour complet, et quoi faire quand le widget disparaît ou arrête de se mettre à jour.

## Ajouter un widget sur l'écran d'accueil

1. Installez l'app et ouvrez-la une fois. (Les widgets apparaissent plus sûrement dans la liste une fois l'app ouverte.)
2. Maintenez le doigt sur un emplacement vide de l'écran d'accueil jusqu'à ce que les icônes se mettent à bouger.
3. Touchez le bouton **+** en haut de l'écran.
4. Cherchez l'app par son nom. Pour nous, c'est Twoodle.
5. Faites défiler les widgets et les tailles disponibles, puis touchez **Ajouter un widget**.
6. Faites-le glisser où vous voulez et touchez **OK**.

Vous pouvez aussi toucher **Modifier** en haut de l'écran pendant que les icônes bougent, puis **Ajouter un widget**. Même résultat.

> **Vous ne l'avez pas encore ?** Twoodle envoie des dessins sur le widget de l'écran d'accueil de l'iPhone de votre partenaire. Téléchargement gratuit. [Télécharger Twoodle](https://apps.apple.com/us/app/twoodle-couples-widgets/id6789469881)

## Quelle taille choisir ?

Avis tranché : voyez plus grand que ce qui paraît raisonnable. Un dessin dans un minuscule widget n'est qu'une tache. Un petit widget convient pour un petit mot d'amour ou un compteur ; un grand est préférable pour un dessin que vous voulez vraiment voir. Regardez dans la liste de l'app que vous utilisez quelles tailles elle propose.

Vous pouvez aussi déposer un widget sur un autre pour former une pile et passer de l'un à l'autre d'un balayage, pratique pour garder le widget de votre partenaire et, disons, votre calendrier au même endroit.

## Ajouter un widget sur l'écran verrouillé

1. Réveillez l'iPhone et maintenez le doigt sur l'écran verrouillé.
2. Touchez **Personnaliser**, puis choisissez **Écran verrouillé**.
3. Touchez la zone de widgets sous l'heure et choisissez un widget.
4. Touchez **OK**.

Tous les widgets ne fonctionnent pas sur l'écran verrouillé, cela dépend de l'app. Voici ce que propose Twoodle :

| Widget Twoodle | Où il se place |
|---|---|
| Dessin | Écran d'accueil |
| Petit mot d'amour | Écran verrouillé ou écran d'accueil |
| Jours ensemble | Écran verrouillé |
| Distance (facultatif) | Widget, seulement si vous activez la localisation |

Les dessins n'arrivent que sur l'écran d'accueil. Si vous espériez un dessin sur l'écran verrouillé, nous avons écrit sur [ce qui est possible ou non](https://twoodle.app/fr/guides/dessiner-sur-iphone-de-son-partenaire/), et sur la façon de [configurer le compteur Jours ensemble](https://twoodle.app/fr/guides/compteur-jours-ensemble-ecran-verrouille-iphone/) pour l'écran verrouillé.

## Widget absent, vide ou pas à jour ?

- **Il n'est pas dans la liste des widgets.** Ouvrez l'app une fois, puis cherchez à nouveau. Toujours rien ? Redémarrez l'iPhone.
- **Il affiche un ancien contenu.** C'est iOS qui décide quand les widgets se rafraîchissent, d'où un léger délai possible après l'envoi de votre partenaire. Ouvrez l'app et vérifiez que les notifications sont autorisées.
- **Rien n'arrive.** Vérifiez que vous êtes bien associés et que votre partenaire a réellement ajouté le widget.
- **Mauvais type de widget.** Les dessins vont sur le widget de l'écran d'accueil, pas sur l'écran verrouillé.
- **Vous voulez en retirer un.** Maintenez le doigt sur le widget, touchez **Supprimer le widget**, puis confirmez.

## Questions fréquentes

### Comment ajouter un widget couple sur l'écran d'accueil de mon iPhone ?

Installez l'app de couple, maintenez le doigt sur un emplacement vide de l'écran d'accueil, touchez le bouton +, cherchez l'app, choisissez un widget et une taille, puis touchez Ajouter un widget. Votre partenaire doit faire de même sur son téléphone.

### Pourquoi je ne trouve pas le widget dans la liste ?

Ouvrez l'app une fois après l'installation, vérifiez qu'elle est bien installée sur cet iPhone, puis relancez la recherche. Si le widget n'apparaît toujours pas, redémarrez l'iPhone et réessayez.

### Puis-je mettre un widget couple sur l'écran verrouillé ?

Certains, oui. Avec Twoodle, le widget Petit mot d'amour peut se placer sur l'écran verrouillé ou sur l'écran d'accueil, et le widget Jours ensemble sur l'écran verrouillé. Les dessins n'apparaissent que sur le widget de l'écran d'accueil.

### Mon partenaire doit-il aussi ajouter le widget ?

Oui. Le widget sur son téléphone est ce qui affiche ce que vous envoyez, donc chacun ajoute le sien.
